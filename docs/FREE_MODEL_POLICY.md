# 免费模型与充值接口规则

2026-10-19，按用户最新明确授权更新。此前“所有供应商均按收费单价卡10元”的执行方式由本规则取代；旧记录不删除、不重新计价。

## 选模型

先读取完整百炼免费目录，按用途选择有文档依据的通用强模型，不再限于千问Flash。当前优先考察 `deepseek-v4-pro-0813`，并纳入 `qwen3.8-max`、`deepseek-v4.1-flash-1017`、`deepseek-v4-flash-0731`、`qwen3.8-27b`、`glm-5.1` 等候选。候选排序是编辑优先级，最终根据本项目任务实测选用，不把模型名称或余额当成质量证明。

语音、图像生成、Embedding、翻译、OCR等专用模型按任务使用，不自动用来回答照护问题。新模型及其具体版本须核对接口能力；JSON Object与JSON Schema分开处理，服务端校验继续保留。通用目录发现、当前账户免费资格和当前构建质量资格是三个独立状态。

## 免费调用

免费调用不设金额预算、不按收费标价挤占充值DeepSeek预算，只记录模型、请求、tokens、余额和待核实用量。每次调用仍要求：控制台登录有效、业务空间匹配、额度未过期、安全可用余额足够且“免费额度用完即停”已开启。

一个合适模型的免费额度不足时，转到下一个已经核对且适合任务的模型。供应商明确报免费耗尽时允许切换；网络、鉴权或一般权限错误不推定为额度用完。已展示正文的失败撤回，不能悄悄拼接不同模型。正式同模型配对固定模型；中途耗尽时保留未完成组，换模型重新组成同模型配对并单独报告。

不自动关闭用完即停，不以余额未知或登录失效为理由切到付费。强模型的免费额度尚可用时，优先继续使用免费池。用户要求使用前说明实际选中的模型，切换后也说明新模型。

## 充值DeepSeek

阿里百炼提供的免费DeepSeek模型属于免费调用；`api.deepseek.com`上用户充值的独立DeepSeek接口属于付费调用。二者按提供服务的接口和免费资格区分，不按模型名字前缀区分。

充值接口继续执行10元现金硬上限和逐请求原子预留。原账本保留全部历史金额：已结算的阿里历史收费等价估算只作参考，不再挤占现金上限；历史供应商不明的金额以及全部未决金额仍保守计入现金责任。原41项未知用量预留不释放，免费token预留账本同样保留。新免费调用在原共享账本中以0现金金额登记tokens，不能另开账本规避历史责任。

`budget_policy`记录新授权口径；`conservative_used_cny`保留旧参考合计，`cash_budget_used_cny`表示现金上限使用及未知责任。两者都不是供应商真实现金账单，不以它们推定账户当前余额。

## 恢复与验收

百炼控制台登录已恢复。CLI错误返回stderr时应解析错误类别；登录过期明确显示过期，不再笼统误报额度不可用或用尽。推理API Key与控制台登录分开保存，不更换原业务Key。

本轮先通过无网络回归验证强模型发现、跨家族切换、免费不限现金预算、充值上限、未知预留与失效资格拦截，再在隔离环境以实际选中模型续做资料及质量/速度验收。运行版资格不因目录扩大而自动升级。

官方接口依据：[百炼DeepSeek](https://help.aliyun.com/zh/model-studio/deepseek-api)、[Qwen3.8-27B](https://help.aliyun.com/zh/model-studio/qwen3-8-27b)。
